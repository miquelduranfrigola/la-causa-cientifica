# book/

The printed book that the site accompanies, and the facsimile pages derived from it.

- `book.yml`: facts about the book and how to trim the PDF.
- `source/`: the book PDF and cover (git-ignored; kept in Google Drive). Expected names: `la-causa-cientifica.pdf`, `cover.jpg`.
- `cover-photo.webp`: the flat cover shown in the book dialog (resized, not retouched), prepared by `scripts/make_cover_photo.py` from `source/cover.jpg`.
- `pages/`: committed facsimiles, one WebP per piece plus a JSON manifest with the exact highlighted sentences. Generated by `scripts/make_book_pages.py`.

Each piece declares where it sits in the book in its `metadata.yml`:

```yaml
book:
  provisional: true        # true until the author has confirmed the passage
  excerpts:
    - page: 87             # printed page number
      sentences:           # exact sentences, as printed; optional while provisional
        - "Text exactly as it appears on the page."
```

Run `python scripts/make_book_pages.py` to rebuild the facsimiles and `code/build_web.py` of each piece to embed them.
